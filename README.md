# 🎵 Moodify - Mood Based Music Recommender

Moodify is a lightweight, cross-platform C++ command-line application that suggests Spotify playlists based on your current emotional state. Just type in your mood, and it will automatically open a handpicked playlist directly in your default web browser!

## ✨ Features
- **Mood Detection:** Supports 4 main moods: `Happy`, `Sad`, `Relaxed`, and `Energetic`.
- **Cross-Platform Support:** Works seamlessly on Windows, macOS, and Linux.
- **Auto-Open:** Uses system-level commands to open Spotify links automatically in your browser.
- **Case Insensitive:** Input `HAPPY`, `Happy`, or `happy` — it understands all!
